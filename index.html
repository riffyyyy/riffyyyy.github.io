A Windows game running on our own engine. No Unity and no Unreal, everything down to the math library (vectors, 3×3 matrices). I was project manager, one of the programmers, and the person the team came to for UX and design calls.

The parts I'm proudest of:

2026 – now · with UXGD students · Unity 6, C#

EduVision

An app for discovering and collecting insect species. I handle the behind-the-scenes side: a Unity editor tool for entering and checking species data, and the export that packs each species into species.json, a .glb model and audio, so the viewer can load it directly.

I also own the collection save data. Each species is stored once by scientific name (scanning it again just bumps a counter), sorted into 10 insect types and 3 rarities, and a corrupted save file won't wipe your progress.
